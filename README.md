# 📊 CDM Talent Intelligence — Executive Command Center & Campaign Analytics Engine

> High-impact, enterprise-grade Talent Intelligence & Executive Campaign Intelligence Dashboard built for Clinical Data Management (CDM) recruitment operations across 9 specialized streams and 122 candidate records.

---

## 🌟 Key Features

* 📊 **100% Real Candidate Data Engine:** Built on 122 real candidate records across 9 specialized CDM roles (*RAVE Programmer, Data Reviewer, UAT Tester, Lab Data Manager, Vendor Data Manager, External Data Manager, Report Programmer, Clinical Programmer, Medical Coder*).
* 🎯 **Dynamic Status Categorization:** Clear breakdown across `Sourced Pool (Awaiting L1)`, `Offered`, `Offer Shortlisted`, `L1/L2 Active Pipeline`, `Interview Rejections`, `Candidate Rejections`, and `No Shows`.
* 🎨 **Bespoke Timeline Color Coding:** Multi-color role palette with **Green End-Caps & Green Badges** (`15-Sep On Time`) for compliant roles, and **Red Overrun Segment & Red Badges** (`🚨 +15D 30-Sep`) for deadline-crossed roles.
* 🔍 **Interactive Studio View:** Maximized full-screen modal mode for per-card deep dives, donut/bar chart toggles, and data sorting.
* 🤖 **AI Assistant Chatbot:** Natural language queries for campaign status, joining probability risk matrices, notice period filters, and TA budget analytics.
* 📄 **Single-File Distribution Bundle (`index_standalone.html`):** Portable single-file web application with zero external dependencies.

---

## 🚀 How to Run Locally

### Option 1: Standalone Single File (Recommended)
Simply open `index_standalone.html` directly in any web browser!

```bash
# Double-click or open in browser
open index_standalone.html
```

### Option 2: Live Node Server
```bash
# Start local Node.js server
node server.js
# Access in browser at http://localhost:8085/
```
